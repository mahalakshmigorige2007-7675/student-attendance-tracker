# 🎓 Student Attendance Tracker

A simple and user-friendly web application for managing and tracking student attendance. The application is built using **Python and Streamlit** and stores attendance data locally using JSON.

## 🚀 Features

- ➕ Add student attendance
- 📋 View attendance records
- ✏️ Edit attendance records
- 🗑️ Delete attendance records
- 📊 Automatically calculate attendance percentage
- 📈 View attendance analytics
- 📅 Track attendance by date
- 🔍 Filter attendance records
- 📥 Download attendance data as CSV
- 💾 Store data locally using JSON
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- JSON
- Streamlit Charts
